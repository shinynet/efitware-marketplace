Version 0.1.38 delivers EF-1889 calendar goal target dates. The calendar card admits the optional `goalDays` record field: the user's active goals whose target date lies inside the range, ordered by date, then name, then goal id. Each goal date gets one flag in the day grid, the selected day lists its goals above its workouts with a link to the goal's page in the application, and the compact card leads with the selected day's goals. Goal days are markers only: session marks, counts, statuses and agenda items are unchanged. The skill's `get_calendar` and `open_calendar` rows describe the field.

Producer requirement: goal days render only from an application that emits `goalDays` in the `get_calendar` response and the `open_calendar` record (application EF-1889), and that application change pins this release. An application that omits the field still validates and shows no goal days. The tool inventory and `contract/server-contract.json`, including its minimum application commit, are unchanged.

Staging creates immutable prerelease assets only. Published catalog promotion must wait for the independently approved compatible application pin to serve exact production READY. External Desktop activation is a separate acceptance surface.
